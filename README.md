# AI-Python-Programs

A beginner-friendly collection of three Python programs demonstrating recursion, loops, and object-oriented programming. Created for a Python programming assignment with AI-assisted documentation.

## Programs

| File | Description | Concept |
| --- | --- | --- |
| `factorial.py` | Calculates the factorial of a non-negative integer. | Recursion |
| `fibonacci.py` | Generates a Fibonacci series for a requested number of terms. | Loops |
| `student.py` | Stores and displays student details using a class. | Classes and objects |

## Technologies Used

- Python 3
- Git and GitHub
- Markdown for documentation

No external Python packages are required.

## How to Run

1. Install Python 3.
2. Clone this repository:

   ```bash
   git clone https://github.com/muditgupta271-ux/AI-Python-Programs.git
   cd AI-Python-Programs
   ```

3. Run any program:

   ```bash
   python factorial.py
   python fibonacci.py
   python student.py
   ```

On systems that use `python3`, replace `python` with `python3`.

## Sample Outputs

### 1. Factorial

```text
Enter a non-negative integer: 5
Factorial of 5 is 120
```

The factorial of 5 is `5 × 4 × 3 × 2 × 1 = 120`. The program uses recursion and rejects negative inputs.

### 2. Fibonacci Series

```text
Enter the number of terms: 7
Fibonacci series: 0 1 1 2 3 5 8
```

The program starts with 0 and 1, then generates each subsequent term by adding the previous two numbers.

### 3. Student Details

```text
Enter student name: Mudit Gupta
Enter roll number: 101
Enter course: B.Tech CSE
Student Details
Name: Mudit Gupta
Roll Number: 101
Course: B.Tech CSE
```

The program creates a `Student` object and displays its stored attributes. The values above are examples; you can enter your own details.
